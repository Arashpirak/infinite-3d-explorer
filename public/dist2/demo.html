🤖 Chatbot Widget Demo

✨ Features

  • ✅ Draggable - Move the widget anywhere
  • ✅ Resizable - Resize from 300x400 to 600x800
  • ✅ Minimizable - Collapse to floating icon
  • ✅ Persian Language Support
  • ✅ Real-time AI Chat
  • ✅ Responsive Design

🎯 How to Use

  1. Look for the robot icon (🤖) in the bottom-right corner
  2. Click it to open the chat widget
  3. Drag the header to move the widget
  4. Drag the bottom-right corner to resize
  5. Click the minimize button (−) to collapse
  6. Type a message and press Enter or click send

💻 Integration Code

To add this widget to your website, simply include this script:

<script src="https://your-domain.com/dist2/embed.js"></script>

For customization:

<script src="https://your-domain.com/dist2/embed.js" data-position="bottom-right" data-custom-title="My Assistant" data-custom-subtitle="How can I help?" data-debug="false"> </script>
📝 Note: This demo connects to the same backend as the main chatbox window. Make sure your API endpoints are working properly.

🔧 Configuration Options

  • data-position - Widget position (bottom-right, bottom-left, etc.)
  • data-custom-title - Custom widget title
  • data-custom-subtitle - Custom subtitle
  • data-custom-icon - Custom icon URL
  • data-api-url - Custom API endpoint
  • data-debug - Enable debug mode

📱 Mobile Support

The widget is fully responsive and works on mobile devices. On mobile, the widget automatically adjusts its size and position for optimal viewing.
